# Credits

External Image Importer is a fork of the **Auto Upload Images** WordPress plugin
by [Ali Irani](https://github.com/airani), released under the GPL-2.0-or-later
licence. This fork continues under the same licence.

The original plugin lives at:

* <https://github.com/airani/wp-auto-upload>
* <https://wordpress.org/plugins/auto-upload-images/>
